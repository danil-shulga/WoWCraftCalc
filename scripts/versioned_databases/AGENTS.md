# Выпуск справочников

- Полный контракт `contract.mjs` применяется к результатам подготовки в `staging`
  и сохраняемым в Git артефактам `data-preparation/releases/<version>`.
  Не ослабляй его ради компактных файлов и не редактируй большие JSON вручную.
- `compact.mjs` проецирует полную базу через актуальный `parseReferenceDatabase`,
  проверяет сериализованный результат и равенство runtime-данных до записи файлов.
  Сохраняй все поля браузерной схемы; при её расширении перевыпускай проекции.
- `release.py` сначала проверяет все версии и готовит проекции, затем сохраняет
  полные артефакты в `releases`, компактные — в `public/data/<version>`.
  Отчёты связывают оба файла с их SHA256. Не оставляй полные базы только
  в игнорируемом каталоге или на сайте. Прежний Forever schema 1 не изменяй.
- Компактные URL определены реестром игры, файлы исключены из Prettier точечно.
  Проверки образцов используют полные базы; приложение и его тесты — компактные.
  Запускай `npm run data:test` и тесты runtime-схемы, поиска и импорта.

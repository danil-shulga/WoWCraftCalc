# CraftCalc: инструкции агенту

- Общайся на русском. Работай небольшими шагами; после каждого изменения укажи
  файлы, цель и фактически выполненную проверку.
- Не делай коммит и push без прямой просьбы пользователя.
- Перед правкой прочитай затрагиваемый код и ближайшие тесты. Сохраняй чужие изменения.
- Сохраняй статическую архитектуру для GitHub Pages и строгие настройки TypeScript.
- Разрабатывай только для десктопа. Не добавляй адаптивные стили для разных размеров
  экрана и не проводи проверки на разных размерах экрана.
- Учитывай `prefers-reduced-motion`: отключай или сокращай анимации.
- Добавление и удаление элементов списков анимируй за 150 мс через высоту
  и прозрачность; порядок реализации описан ниже.
- Расчёты размещай в `src/domain`, изменения каталога — в действиях `src/store`.
- Перед созданием или изменением интерфейса прочитай
  [ui-and-features.mdc](.cursor/rules/ui-and-features.mdc), сверься с картой компонентов
  и найди подходящие реализации в коде. Переиспользуй существующие компоненты;
  повторяющиеся элементы выноси в компоненты вместо копирования JSX и CSS.
  Вид, содержимое, действие и состояние элемента задавай через props общего
  компонента; это относится и к кнопкам, и к сочетаниям вроде иконки с названием предмета.
- Не исправляй замечания из обзора и не проводи рефакторинг вне текущей задачи.
- При изменении поведения, формата данных, команд или общих компонентов обновляй
  соответствующее описание и тематическое правило; фиксируй реализованное состояние,
  а исторические планы не используй как список текущих задач.

## Анимация элементов списков

- Переиспользуй существующую реализацию; примеры — строки `PlannerPage`
  и состав рецепта `RecipeEditor`. Для одинаковых строк используй общую разметку
  и стили, не копируй анимацию для каждого вида списка.
- Для строки используй внешнюю grid-оболочку с `grid-template-rows: 0fr → 1fr`
  при добавлении и `1fr → 0fr` при удалении; одновременно меняй `opacity: 0 ↔ 1`.
  Длительность — `150ms`, плавность — `ease-out`. Внутренней обёртке задай
  `min-height: 0` и `overflow: hidden`; отступы между строками размещай внутри
  схлопываемой области, чтобы они тоже исчезали плавно.
- Изменяй данные сразу; уходящую строку сохраняй отдельно в состоянии отображения
  со стабильным ключом и последними данными. Сразу задавай ей `inert` и `aria-hidden`.
  Удаляй её из DOM после собственного `animationend`, игнорируя события потомков.
- Сохраняй оболочку списка до завершения удаления последней строки, в том числе
  при массовой очистке. Повторное добавление той же позиции должно отменять удаление
  без дублирования строки; изменение количества не должно запускать её появление заново.
- При `prefers-reduced-motion: reduce` сокращай анимацию до `1ms`, если удаление
  зависит от `animationend`; не отключай событие, оставляя строку навсегда в DOM.
- Проверяй добавление, удаление последней строки, очистку и быстрое повторное
  добавление; расчёты и сохранение не должны ждать завершения анимации.

## Контекст по необходимости

Файлы `.cursor/rules/*.mdc` — тематические инструкции. Не читай их все заранее:
выбирай по задаче, а при переходе в другую область открывай соответствующий файл.

- Первое знакомство, устройство приложения, добавление слоя или зависимости:
  [project-overview.mdc](.cursor/rules/project-overview.mdc).
- Версии игры, деньги, модель предметов, рецепты и сценарии прибыли:
  [architecture-and-data.mdc](.cursor/rules/architecture-and-data.mdc).
- Zustand, сохранение, миграции и резервные копии JSON:
  [state-and-persistence.mdc](.cursor/rules/state-and-persistence.mdc).
- Страницы, редакторы, дерево, общие компоненты, CSS и доступность:
  [ui-and-features.mdc](.cursor/rules/ui-and-features.mdc).
- Ссылки, tooltip, сетевые запросы и сопоставление предметов Wowhead:
  [wowhead-import.mdc](.cursor/rules/wowhead-import.mdc).
- Справочники schema 2, импорт из базы, исходные CSV и подготовка наборов:
  [reference-databases.mdc](.cursor/rules/reference-databases.mdc).
- Источники цен TSM, выбор используемой цены, кэш и публикация снимков:
  [tsm-pricing.mdc](.cursor/rules/tsm-pricing.mdc).
- Выбор проверок, конфигурация инструментов и подготовка результата:
  [coding-workflow.mdc](.cursor/rules/coding-workflow.mdc).

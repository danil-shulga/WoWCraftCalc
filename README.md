# CraftCalc

Локальный калькулятор выгоды крафта для WoW Forever, TBC и Classic. Приложение
работает без сервера.

## Возможности

- независимые каталоги предметов, цен, рецептов и профессий для трёх версий;
- выбор версии в настройках или через логотип, с собственной тёмной палитрой;
- выборочное добавление предметов из локальных справочников schema 2;
- рецепты произвольной глубины;
- выбор покупки или крафта для каждого реагента;
- расчёт себестоимости и прибыли с учётом количества результата;
- цены в золоте, серебре и меди;
- цены TSM для TBC: выбор рынка и показателя, источники покупки/продажи и режим всего списка;
- локальное сохранение в браузере;
- экспорт и импорт резервной копии JSON;
- защита от циклических рецептов.

Вкладки «Выгодные» и «Любимые» пока являются заглушками.

Текст интерфейса не выделяется при кликах и перетаскивании мыши, в том числе
при сворачивании и разворачивании строк рецепта. В полях ввода выделение сохранено.

В переключателе «Авто / Купить / Крафтить» кнопка «Авто» имеет компактную ширину
72 px. Подсветка выбранного варианта перемещается за 0,15 секунды; при настройке
системы на уменьшение движения переключение происходит без анимации.

Под заметкой о хранении данных в боковой панели показаны три строки: «localStorage:»,
«занято ≈ …», «осталось ≈ …» в мегабайтах (МБ = 1 000 000 байт), до двух знаков после запятой,
для всех записей localStorage сайта, включая кэш TSM. Объём оценён по размеру
ключей и значений UTF-16, остаток — от типичного лимита 5 МиБ, а не точной квоты
браузера. Индикатор обновляется каждые две секунды, при возврате фокуса и изменениях
из другой вкладки; при отказе доступа показывает «localStorage недоступен».

В режиме «Редактировать цены» суммы располагаются справа от названия предмета.
Длинное название переносится по строкам; редактор и соседние суммы выровнены
по одинаковым колонкам во всех строках. Правый блок занимает только ширину
своих колонок, оставляя остальное место названию. Поля цены доступны сразу, без галочки
разблокировки. Неизменённая неизвестная цена сохраняется как неизвестная;
ввод суммы, в том числе нуля, задаёт ручную цену.

## Импорт рецептов Wowhead

В разделе «Крафты» нажмите «Добавить крафт», затем «Импорт из Wowhead» и вставьте HTTPS-ссылку на
заклинание (`spell=`) для Classic, TBC или Forever. После загрузки проверьте
список ингредиентов, количество предметов за один крафт и профессию.

Явный выход в tooltip подставляется из Wowhead. Если выход не распознан и нет
сохранённого локального значения, в поле стоит `1`; при необходимости измените
количество. Профессию крафта выберите сами либо явно укажите
«Без профессии»: требования к использованию готового предмета не определяют
профессию его изготовления. Выбор профессии влияет на автоматическое получение
реагента: `auto` допускает крафт только при владении указанной профессией.

При повторном импорте подставляются сохранённые локальные выход и профессия;
они подписаны отдельно от данных Wowhead и доступны для изменения. Проверьте
параметры и нажмите «Подтвердить импорт» — дополнительного чекбокса нет.
До нажатия этой кнопки и при отмене каталог не меняется.

Повреждение хотя бы одного ингредиента отклоняет весь рецепт. Отсутствие
количества ингредиента означает одну единицу; инструменты и условия в состав
не входят. Импорт сохраняет цены, вложенные рецепты и ручной выбор покупки
или крафта, сопоставляя предметы по Wowhead item ID или единственному совпадению
нормализованного имени. Версия источника сохраняется вместе с item ID. Ссылка из другой версии игры
отклоняется; импорт не переключает версию автоматически.

## Локальный запуск

Интеграция TSM и подготовка локальных снимков описаны в [документации TSM](docs/tsm-tbc.md).

Понадобятся Node.js 22.12+ (рекомендуется LTS) и Python 3.12+ для подготовки цен TSM.

```shell
npm install
npm run dev
```

Перед запуском автоматически загружаются снимки TSM для локального сервера.
Vite выведет локальный адрес приложения в терминале. Для обновления цен без
перезапуска используйте `npm run tsm:refresh:dev` и кнопку «Проверить обновление».

## Проверка и исправление кода

```shell
npm run typecheck
```

Проверяет строгие правила TypeScript без создания файлов сборки.

```shell
npm run lint
npm run lint:fix
```

Первая команда показывает ошибки ESLint. Вторая автоматически исправляет только
безопасно исправляемые ошибки. Оставшиеся сообщения нужно проверить вручную.

```shell
npm run format:check
npm run format
```

Проверяет форматирование Prettier или форматирует проект.

```shell
npm run test
npm run check
npm run data:test
npm run tsm:test
```

`test` запускает тесты один раз. `check` последовательно проверяет TypeScript,
ESLint, форматирование и тесты приложения. `data:test` отдельно проверяет
подготовку справочников (Python и Node.js), `tsm:test` — обработчик цен (Python).
Они не входят в `check`; при изменениях соответствующих скриптов запускайте их отдельно.

Не отключайте правило ESLint без необходимости. Если исключение действительно
нужно, оставьте рядом короткий комментарий с технической причиной.

## Пользовательские данные

В `localStorage` под ключом `craft-calc-versioned-data` (persistence v1) хранятся
`activeVersion`, три `workspaces` с `items` и `ownedProfessions`, а также общие
`currencyDisplay` и `itemLanguage` и отдельные настройки `tbcPricing`.
Ручные цены и источники покупки/продажи входят в каталог; внешний кэш TSM не входит
в резервную копию. По умолчанию выбран Forever; все каталоги пустые.
Переключение сохраняет свой каталог, остаётся в текущем разделе и сбрасывает поиск,
раскрытие дерева и временный UI. Несохранённые формы, цены и предпросмотры требуют
явного выбора: отменить переключение или отбросить изменения.

Прежний ключ `craft-calc-data` удаляется при запуске. Старые данные и резервные
копии не переносятся: предметы нужно добавить заново.

«Экспорт JSON» создаёт полную копию `craftcalc-versioned-backup` v1 всех трёх
каталогов, выбранной версии и общих настроек. Справочники туда не входят.
Импорт проверяет каждый каталог, его граф и версию источников, затем атомарно
заменяет все данные после предупреждения. При отказе записи импорт и сброс
сохраняют текущие данные; ошибка обычного сохранения показывается в интерфейсе.
Данные не синхронизируются между устройствами, поэтому регулярно сохраняйте копию.

## Добавление из базы

В окне добавления выберите «Из базы». Загружается только справочник активной версии:
Forever beta `1.60.1.70338`, TBC Anniversary `2.5.6.69795` или Classic Era
`1.14.4.51829`. Подробности происхождения — в [описании баз](docs/versioned-databases.md).
Профессии ограничены своей версией; ювелирное дело доступно только в TBC.

Справочники содержат кандидаты из клиентских таблиц; присутствие рецепта не
подтверждает доступность в игре. Выберите один из альтернативных рецептов и
явно введите положительный целый выход. Кандидат из эффекта не подставляется.
NPC-цены показаны с происхождением, размер пачки не пересчитывается. Рыночные цены
задаются вручную или берутся из TSM для TBC после выбора источника.
Повторное добавление сохраняет цены,
вложенные рецепты и ручной способ получения; выбранный активный рецепт заменяется
только после подтверждения. Сами справочники не изменяются.

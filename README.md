# CraftCalc

Десктопный калькулятор себестоимости и прибыли крафта для **WoW Forever,
TBC Anniversary и Classic Era**. Статическое приложение на React и TypeScript,
работает без сервера и публикуется на GitHub Pages.

- Каталоги предметов и рецептов отдельно для каждой версии игры.
- Расчёт вложенных рецептов с выбором покупки или изготовления реагентов.
- Планировщик целых партий, общий список покупок и избранное.
- Добавление предметов из справочников и импорт рецептов из Wowhead.
- Ручные цены и снимки цен TSM для TBC.

Данные сохраняются в браузере; резервную копию JSON можно экспортировать
и импортировать в настройках. Для внешних источников нужна сеть.
Раздел «Выгодные» пока не реализован.

## Запуск

Нужны Node.js 22.12+ и Python 3.12+ для подготовки снимков TSM.

```shell
npm ci
npm run dev
```

Перед запуском автоматически обновляются локальные снимки TSM.

## Проверка и сборка

```shell
npm run check
npm run build
npm run preview
```

`check` запускает TypeScript, ESLint, Prettier и тесты приложения.
Отдельные проверки скриптов: `npm run data:test` и `npm run tsm:test`.
Результат сборки — каталог `dist`.

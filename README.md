# CraftCalc

Небольшой локальный калькулятор выгоды крафта для WoW Classic. Приложение
работает без сервера и подходит для публикации на GitHub Pages.

## Возможности первой версии

- единый каталог предметов и реагентов;
- рецепты произвольной глубины;
- выбор покупки или крафта для каждого реагента;
- расчёт себестоимости и прибыли с учётом количества результата;
- цены в золоте, серебре и меди;
- локальное сохранение в браузере;
- экспорт и импорт резервной копии JSON;
- защита от циклических рецептов.

Вкладки «Выгодные» и «Любимые» пока являются заглушками.

## Локальный запуск

Понадобится актуальная LTS-версия Node.js.

```shell
npm install
npm run dev
```

Vite выведет локальный адрес приложения в терминале.

## Проверка и исправление кода

```shell
npm run typecheck
```

Проверяет строгие правила TypeScript без создания файлов сборки.

```shell
npm run lint
npm run lint:fix
```

Первая команда показывает ошибки ESLint. Вторая автоматически исправляет только
безопасно исправляемые ошибки. Оставшиеся сообщения нужно проверить вручную.

```shell
npm run format:check
npm run format
```

Проверяет форматирование Prettier или форматирует проект.

```shell
npm run test
npm run check
```

`test` запускает тесты один раз. `check` последовательно проверяет TypeScript,
ESLint, форматирование и тесты. Эту команду стоит выполнять перед коммитом.

Не отключайте правило ESLint без необходимости. Если исключение действительно
нужно, оставьте рядом короткий комментарий с технической причиной.

## Сборка

```shell
npm run build
npm run preview
```

Готовые статические файлы появятся в каталоге `dist`.

## GitHub Pages

1. Создайте репозиторий GitHub и отправьте проект в ветку `main`.
2. Откройте `Settings → Pages`.
3. В разделе `Build and deployment` выберите источник `GitHub Actions`.
4. Workflow проверит проект, соберёт его и опубликует каталог `dist`.

Конфигурация Vite использует относительные пути, поэтому сайт работает как в
корне GitHub Pages, так и по адресу репозитория.

## Пользовательские данные

Каталог хранится в `localStorage` текущего браузера и не синхронизируется между
устройствами. Регулярно используйте кнопку «Экспорт JSON». При импорте файл
проверяется, после чего полностью заменяет текущий каталог.

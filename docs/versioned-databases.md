# Подготовка отдельных справочников

Справочники schema 2 готовятся независимо из клиентских таблиц Wago. Они содержат
результаты включённых рецептов и их непосредственные расходуемые реагенты,
а также материалы профессиональных зачарований и связанных превращений предметов.
Приложение подключает эти справочники через реестр `src/domain/game-version.ts`:
при добавлении загружается только активная версия. Пользовательские каталоги,
цены, рецепты и профессии изолированы в трёх workspace. Подготовка исходных
таблиц и подключение справочников к приложению остаются отдельными этапами.

## Зафиксированные снимки

- Classic Era: `wow_classic_era`, `1.14.4.51829` от 20.10.2023. Выбран снимок до
  появления SoD, а не современный общий клиент Era/SoD. Это исторические данные Era,
  а не обещание актуальности цен и рецептов на 2026 год.
- TBC Classic Anniversary: `wow_anniversary`, `2.5.6.69795`. Вариант выбран
  пользователем; архивный TBC Classic и оригинальный клиент 2.4.3 не использованы.
- Forever beta: `wow_classic_beta`, `1.60.1.70338`. Предоставленные CSV проверены
  по SHA256 прежней базы; соответствие старых имён и локалей записано в манифесте.

Продукты, полные сборки и конфигурации проверены по
[списку сборок Wago](https://wago.tools/api/builds). Classic-снимок предшествует
[анонсу SoD от 03.11.2023](https://worldofwarcraft.blizzard.com/en-gb/news/24023090/world-of-warcraft-classic-season-of-discovery-announced-at-blizzcon).
Дата подготовки зафиксирована как `2026-10-12` и не меняется при повторной сборке.

## Файлы и происхождение

Выходные файлы:

- `public/data/classic/craftcalc-db.1.14.4.51829.json`.
- `public/data/tbc/craftcalc-db.2.5.6.69795.json`.
- `public/data/forever/craftcalc-db.1.60.1.70338.json`.

В `data-preparation/manifests` лежат восемь источников на базу: точные URL,
локали, продукт, сборка, число строк и SHA256. Все таблицы одной базы относятся
к одному снимку. `raw`, `cache` и `staging` находятся вне `public`, исключены
из Git и не попадают на сайт. Эти папки нужно сохранять отдельно для автономной
пересборки без внешних сервисов.

`scripts/versioned_databases/build.py` задаёт явные адаптеры трёх проверенных
CSV-схем. Неподдержанная сборка, отсутствующий столбец, повтор ID, несовпадающий
хеш или смешанные источники останавливают сборку. Профессии связаны через
`ParentSkillLineID`; TBC сохраняет ювелирное дело. Повреждённый рецепт исключается
целиком с причиной. Альтернативные рецепты остаются самостоятельными записями.

Контракт `scripts/versioned_databases/contract.mjs` проверяет schema 2, двенадцать полей
предмета, метаданные, источники, состав, двусторонние ссылки, точный охват предметов
и пересчитанную статистику. Внешние инструменты не расширяют каталог; порядок
и повторяющиеся слоты инструментов сохранены из CSV. Циклы между альтернативными
способами получения допустимы.

Предметы всех трёх баз сохраняют метаданные своего снимка:

- `itemId` — `Item.ID`, для сопоставления с Wowhead и исключениями;
- `qualityId` — `ItemSparse.OverallQualityID`, качество;
- `requiredLevel` — `ItemSparse.RequiredLevel`, требуемый уровень;
- `itemLevel` — `ItemSparse.ItemLevel`, уровень предмета для выбора диапазона дизенчанта;
- `classId` — `Item.ClassID`, класс предмета (оружие, броня и другие);
- `subclassId` — `Item.SubclassID`, уточнение типа и обработка исключений;
- `inventoryType` — `ItemSparse.InventoryType`, слот экипировки.

`requiredLevel` и `itemLevel` независимы. Все шесть полей метаданных — обязательные
неотрицательные целые в справочнике; ноль сохраняется как исходное значение.
Значения не нормализуются и не заимствуются из другой версии игры. Импорт результата,
реагентов и отдельного предмета переносит эти метаданные в пользовательский каталог,
localStorage и JSON backup. Для старых и ручных предметов поля необязательны,
`null` или отсутствие означает неизвестное значение. Повторный импорт обновляет
известные значения из базы; источник без этих сведений не стирает сохранённые.
Существующий каталог получает сведения при повторном импорте предмета или рецепта.

`itemScope: recipe-products-and-profession-reagents` расширяет состав предметов
без изменения рецептов крафта. `reagentSources` хранит расходуемые материалы
профессиональных зачарований (`Effect = 53`, корневая профессия 333) и превращений
без связи с профессией (`Effect = 24`). Для каждой записи сохранены ID заклинания,
строки эффекта, состава и связей профессии. Состав должен быть полным, положительным,
без повторов и конфликтов локалей. Превращения включаются только для одного
расходуемого реагента, когда результат и реагент относятся к торговым товарам
(`Item.ClassID = 7`), а результат уже связан с каталогом; цепочки обходятся до
замыкания. Несвязанные превращения и инструменты каталог не расширяют.

Эти записи не являются рецептами крафта: у предметов не появляются вымышленные
профессии или подтверждённый выход. Число в `SpellReagents` сохраняется как исходное
значение и не считается полным расходом превращения: сам используемый предмет
может расходоваться отдельно. Поиск реагентов учитывает `reagentSources`, фильтр
профессии — зачарование и профессии, использующие результат превращения.
Статистика `reagentItems` включает дополнительные материалы. Старые базы без
`reagentSources` по-прежнему читаются. Сравнение Forever с прежней schema 1 проверяет
неизменность прежних полей предметов и рецептов (добавленные `requiredLevel`,
`itemLevel`, `classId`, `subclassId`, `inventoryType` берутся из исходных CSV);
новые реагенты перечисляются
отдельно в `additionalItemIds` отчёта подготовки.

## Повторение подготовки

Нужны Node.js из `package.json`, установленные зависимости и Python 3.12+.
Команды выполнять из корня проекта. Сеть нужна только для скачивания исходников,
новых tooltip и проверки HTTP-доступности нескольких иконок.

```powershell
python scripts/versioned_databases/sources.py --discover
python scripts/versioned_databases/sources.py --version classic --mode era --product wow_classic_era --build 1.14.4.51829
python scripts/versioned_databases/sources.py --version tbc --mode anniversary --product wow_anniversary --build 2.5.6.69795
python scripts/versioned_databases/sources.py --version forever --mode beta --product wow_classic_beta --build 1.60.1.70338 --import-dir C:/Users/BGFox/Downloads

python scripts/versioned_databases/build.py data-preparation/manifests/forever.1.60.1.70338.json
python scripts/versioned_databases/build.py data-preparation/manifests/classic.1.14.4.51829.json
python scripts/versioned_databases/build.py data-preparation/manifests/tbc.2.5.6.69795.json

python scripts/versioned_databases/icons.py data-preparation/staging/craftcalc-db.classic.1.14.4.51829.json
python scripts/versioned_databases/icons.py data-preparation/staging/craftcalc-db.tbc.2.5.6.69795.json

python scripts/versioned_databases/build.py data-preparation/manifests/classic.1.14.4.51829.json
python scripts/versioned_databases/build.py data-preparation/manifests/tbc.2.5.6.69795.json

node scripts/versioned_databases/verify-samples.mjs data-preparation/staging/craftcalc-db.classic.1.14.4.51829.json data-preparation/staging/craftcalc-db.tbc.2.5.6.69795.json data-preparation/staging/craftcalc-db.forever.1.60.1.70338.json
npm run data:test
python scripts/versioned_databases/release.py
```

Если исходники Forever отсутствуют, ту же сборку можно скачать с Wago командой
без `--import-dir`. Это новая выгрузка: её хеши могут отличаться от предоставленного
снимка. Не заменять исходники или готовые файлы молча. Данные и конфигурации
исторической сборки на внешнем сервисе могут стать недоступны.

Скрипт иконок использует два потока, паузу 0,2 секунды после запроса, таймаут
20 секунд и максимум три попытки при временной сетевой ошибке. При 403/429
запросы останавливаются. Кеш привязан к версии и itemId; несовпадающее EN-имя,
404 или повреждённый ответ оставляют пустой URL и запись в отчёте. Для повторной
проверки конкретной ошибки удалить только её запись из кеша соответствующей
версии после разбора причины. Полные tooltip и сами изображения на сайт не включены.

`release.py` сначала дважды собирает каждый набор, сравнивает байты и проверяет
все три базы, кеши и выборочные HTTP-проверки. Затем копирует готовые файлы
в `public/data/<version>` и проверяет сохранённые JSON. Прежний Forever schema 1
сохраняется; в отчёте выпуска записан его контрольный хеш. Коммит и push не входят
в команды подготовки.

## Отчёты и ограничения

В `data-preparation/reports`:

- `<version>.<build>.json`: итоговый файл и SHA256, количества, распределение
  по профессиям, исключённые рецепты, несовпадения локалей, пропуски переводов,
  иконок и неизвестный выход. Для Forever — сравнение с прежними предметами,
  рецептами и профессиями.
- `icons.<version>.<build>.json`: результаты обработки tooltip и ошибки.
- `samples.<version>.<build>.json`: результаты проверки известных рецептов
  и HTTP-статуса/Content-Type нескольких CDN-иконок.
- `release.json`: побайтная воспроизводимость, хеши файлов и различия между
  версиями при совпадающих ID.

Наборы явно помечены как **кандидаты из таблиц клиента** в метаданных и отчётах.
Проверка доступности каждого рецепта игроку не выполнена: скрытые, тестовые и
устаревшие записи могут сохраняться. Выбранный Classic-снимок не содержит добавлений
SoD из последующих сборок. Подозрительные названия перечисляются отдельно;
их отсутствие не доказывает доступность всех рецептов. В Forever сохранён
`23567` с исходным названием `DEPRECATED ITEM`, без заявления о его доступности.

`output.quantity` остаётся `null`. Исходные параметры эффекта и положительный
базовый кандидат сохраняются без универсального прибавления единицы. Даже если
выборочный Wowhead-tooltip сообщает выход, он записывается только в отчёт,
а не превращается в массовое подтверждение схемы. Tooltip относится к версии игры,
но не закреплён за исторической клиентской сборкой.

`BuyPrice`, `SellPrice` и `VendorStackCount` сохраняются из своей версии без
пересчёта. Ноль отличён от отсутствующего значения; продажа NPC не подтверждена.
Семантика цены пачки и массовое подтверждение выхода остаются отдельными этапами.
У многих item-tooltip нет ID в теле ответа: проверяются исходный URL версии/itemId,
точное EN-имя и ID, когда он возвращён. Проверка нескольких изображений не означает
проверку HTTP-доступности каждой CDN-ссылки.

# Примеры tooltip Wowhead

Ответы сохранены без изменения содержимого 2026-10-11 из публичного endpoint
Wowhead. Тесты читают локальные JSON; сетевые вызовы в тестах замоканы.

- [Classic, spell 25146](https://nether.wowhead.com/classic/ru/tooltip/spell/25146):
  трансмутация, выход `(3)` после `span` результата; один ингредиент без количества.
  Название заклинания отличается от названия результата.
- [TBC, spell 44391](https://nether.wowhead.com/tbc/ru/tooltip/spell/44391):
  робот, выход `(5)`, инструменты отдельно от состава, третий ингредиент без
  количества. `Требует skill=202` находится в описании использования предмета;
  этот фрагмент не подтверждает профессию крафта.
- [Forever, spell 1257390](https://nether.wowhead.com/forever/ru/tooltip/spell/1257390):
  кушак, выход `(2)`, четыре ингредиента с явными количествами.

Подтверждён только явный положительный целый выход после ссылки на результат.
Отсутствие выхода, диапазоны и другие формы не интерпретируются как единица.
Форма при неизвестном выходе подставляет `1`, если нет сохранённого значения,
и подписывает это как значение по умолчанию, а не данные Wowhead.
Профессию крафта из этих ответов достоверно определить нельзя; её подтверждает
пользователь. Повреждённые варианты создаются тестами из сохранённых примеров
или небольших локальных HTML-фрагментов.

# Добавление из справочника

- Поиск использует неизменяемый индекс загруженной базы: нормализованные имена
  и готовый порядок RU/EN отдельно для каждого раздела. При запросе и фильтре
  профессии не сортируй результаты заново; у равных имён сохраняй исходный
  порядок своего раздела. После изменения данных создавай новый индекс.

- Для добавления используй один набор и `onImportBatch`, даже если выбран один
  предмет. `targetItem` означает только одиночный целевой импорт редактора.
- Настройки каждой выбранной позиции сохраняй при поиске, смене страницы,
  профессии, предпросмотра и вкладки источника. Первый клик по результату добавляет
  предмет, второй убирает; отдельных флажков нет. Клик в списке выбранных
  только переключает предпросмотр. Новые выбранные позиции добавляй в начало
  списка; не прокручивай окно вниз при выборе или смене предпросмотра.
- До общего подтверждения изменяй только локальные черновики. Весь набор передавай
  одному `importReferenceBatch`; не заменяй его циклом одиночных действий store.
- Ошибка позиции сохраняет набор и указывает предмет. Отказ persistence не должен
  приводить к уведомлению об успешном сохранении или закрытию формы.
- Предпросмотр состава и выхода переиспользуй между добавлением и редактором.
  Правила разрешения общих предметов и проверки конечного графа находятся
  в [описании импорта](../../../docs/versioned-databases.md#выбор-нескольких-предметов).
